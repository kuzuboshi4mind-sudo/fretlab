# Fretlab ギター練習帳

ギタリストのための練習アプリ。1つのHTML（`fretlab.html`）から、Web版（PWA）・Android・iOS アプリを作ります。

## 機能
- **メトロノーム**：BPM 30〜260、タップテンポ、拍子（分子・分母のダイヤル）・音符（4分・8分・3連・16分）、音色11種（クリック1〜3、録音した機械式メトロノームの音など）
- **ドラムパターン**：8ビート／16ビート（それぞれバウンスも）、ファンク／ソウル、ボサノヴァ、レゲエ、ジャズ・スウィング、ハードロック、ワルツ、6/8 など15種。ジャンルごとの本物のドラムセット（MuseScore_General、MIT）で、人が叩いているように強さとタイミングを揺らし、8小節ごとにフィル
- **チューナー**：マイクで音程測定（ページを開くとすぐ測定、±セント表示、画面いっぱいにゆっくり振れる針、背景の色8色、まわりの雑音を拾いにくい判定）、基準音、7種のチューニング、A4=430〜450Hz
- **楽器の切り替え**：コード・進行・指板・スケール・弾語り練習・TAB をギター／ウクレレ／ベース（4弦・5弦）で表示・再生
- **コード一覧**：12ルート×17タイプ、1コードにつき2〜4通りの押さえ方、度数表示。自由入力でオンコード（D/F#、C on E）やテンションコード（G13、C7(#9,b13) など）も表示
- **コード進行**：定番の進行150パターン（ジャズ・ボサノヴァ・ラテンはテンションやオンコード入り。全キーに移調）と、自分で書いた進行（オンコード・テンションも可、保存できる）を、ドラム＋伴奏（アルペジオ3種・スリーフィンガー／4分・8分・8ビート・16ビートのストローク）に合わせて再生。鳴っている場所を指板で光らせる。ジャズの進行をベースで弾くとウォーキングベース
- **指板音程表**：音名／度数／ドレミ表示、22フレットまで表示、タップした音を五線譜とTABで表示（ト音・ヘ音記号）、指板クイズ
- **スケール表**：13スケール、22フレットまでのポジション別表示、タップした音を五線譜とTABで表示
- **弾語り練習**：名曲・伝承曲48曲の歌詞つきコード譜（全曲メロディつき）。コード名の横に小さな押さえ方の図（横向き）が出るので、歌詞を見ながら弾ける。難易度は「易（元のコード）・中（セブンス）・難（9th・13th・♭9・♯11 などのテンション）」の3段階（キー変更、カポ提案、使うコードの図、速さ50〜200%）
- **TAB練習**：カラオケボタンで主旋律を消して伴奏だけにできる。メロディ50曲・クラシック20曲・トラディショナル20曲（ラグタイム・スウィング・スピリチュアル）・リフ6本・基礎練習9本（クロマチック、スパイダー、スケール、オルタネイト、弦飛び、アルペジオ）。再生すると今弾く音が光る（速さ50〜120%、ループ）。伴奏つき：メロディは歌のコード（または自動で付けたコード）をギターで、リフはドラムとベース、スウィングの曲はドラムとウォーキングベース（ブルース・シャッフルは12小節のブルース進行）
- **マイ記録**：自分で名前と時間を決めるタイマー（5つまで。0になったら知らせて、止めるまで数え続ける）、日・週・月・年の振り返り（合計・棒グラフ・タイトル別の円グラフ）、記録の追加・修正・削除、累計時間のトロフィー（10分〜10000時間の18段階。バナーとタイマーの着せ替えがもらえる）、連続日数、バックアップ
- **オープニング**：線画のギターとロゴ。「はじめる」を押すと和音が鳴り、風が吹いて緑の葉が流れ、弦が揺れてからアプリへ
- **カラー**：ライト・ダーク・セージ・サクラ・スカイ・ライトウッド・ネイビー・ボルドーの8種類から選べる（右上のボタン）
- **練習Tips**：コツと30分メニュー
- **レッスンコーチ**（準備中）：AI先生にギターの質問をして答えてもらう（`worker/` に API）

収録曲は、作詞者・作曲者の没後70年以上が経過した曲、または伝承曲のみです。現在の流行曲の歌詞やメロディは著作権で保護されているため収録していません。

## 使い方

### Web版（PWA）
```bash
npm run serve        # http://localhost:8080 で確認
```
GitHub に push すると `pages.yml` が GitHub Pages に公開します（リポジトリの Settings → Pages → Source を「GitHub Actions」に）。
公開URLをスマホで開き、「ホーム画面に追加」（iPhone は Safari の共有メニュー）でアプリとして使えます。一度開けばオフラインでも動きます。
マイクは https か localhost でのみ使えます。

### Android
```bash
npm install
npm run android      # Android Studio が開く → ▶ で実機/エミュレータに転送
```
Android Studio がなくても、GitHub の Actions → 「Build Android APK」→ Run workflow で APK を作れます（Artifacts からダウンロード）。

### iOS
macOS と Xcode が必要です。
```bash
npm install
npm run ios          # Xcode が開く → Signing で自分の Apple ID を選び ▶
```
App Store で配布するには Apple Developer Program（年額）への登録が必要です。Google Play も開発者登録（初回のみ）が必要です。

## 更新の流れ
`fretlab.html` を編集 → `npm run cap:sync`（ネイティブ）または push（Web版）。
